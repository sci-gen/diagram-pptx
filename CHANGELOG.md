## [0.1.0] - 2026-07-26

### Added

- Renderer-neutral diagram and positioned-layout intermediate representations.
- Mermaid flowchart and JSON importers.
- Deterministic layered layout with LR, RL, TB, and BT directions.
- Native `python-pptx` AutoShape, connector, group outline, and label rendering.
- Mermaid node styles, subgraphs, edge labels, cycles, and self-loop support.
- Command-line Mermaid-to-PPTX conversion.
- Docker-based tests and LibreOffice/Poppler visual verification.
